- **Opening a project keeps a newer runtime (pull request 88, Xehanort88).** Opening a project no longer replaces a newer runtime with the editor's older one without asking. The editor used to copy its own runtime into a project's `js/` whenever the two differed, so opening a project in an older install (an earlier release, or a build from an older checkout) quietly downgraded the game. Now, when the project's runtime has a later version, or the same version and a later revision, the editor asks first: **Keep Project Runtime** (the default, and what Enter and Escape choose) or **Replace with Older Runtime**. A project with an older runtime is still updated on open, without a question.

- **Audio: `.opus` files play without being renamed (pull request 87, Xehanort88; merged into runtime 20261117.11).** The game, the editor and Deploy Game take Ogg Opus under the `.opus` extension that `opusenc` and FFmpeg write, beside `.ogg .mp3 .wav .flac .m4a`. The runtime tries it last (`Utils.AUDIO_EXTENSIONS`), so a folder holding both `Theme.ogg` and `Theme.opus` still plays `Theme.ogg`, and a web build's failed request reaches it after `.m4a`. Every audio picker, the Audio Player, the Resource Manager and the music sequence preview list it, and the vehicle sound checks find it. The Resource Manager imports it, as `.opus_` in a project with encrypted audio, and an encrypted `.opus_` previews in the editor as `audio/ogg`. Web builds serve it as `audio/ogg`. Deploy Game encrypts it to `.opus_` with the other sounds and never re-encodes it: like Opus named `.ogg`, it ships as it is. Audio command names also lose a `.flac` or `.opus` extension now, and the Pinnacle GTBS scene's sound check finds `.flac` and `.opus`. Tested in `tests/opus-extension.test.cjs`. RPG Maker MZ asks for `.ogg` only, so a project that must also play there should keep its Opus files named `.ogg` ([guide](../../docs/AUDIO-LOOP-POINTS.md)).
