### Fixed

- **Wearable finishes:** sharp cape hem and scarf patterns replace blended vertex colors. Capes have a plain inner lining; scarves offer Solid, Stripes and Checks. Boot contours get finer sampling and additional smoothing along the outer edge.
- **Prop catalog:** consolidated wearable headwear, masks, eyewear, packs and harnesses; separated clothing subgroups; grouped interiors and stage gear consistently. Energy weapons sit with their families. The older duplicate Necktie is hidden while saved recipes remain loadable.

- **Boot and shoe soles:** smooth the shared sole/welt outline instead of carrying sparse foot samples into abrupt heel and side notches. Foot clearance, toe reach and heel length are retained. Applies to procedural footwear in both Character Builder and Props → Wearables.

- **Officer jacket:** removed the floating chest flap, competing zipper/button rows and bulky chest pockets. Shoulder colors join into the collar; fitted insignia, one concealed closure and shallow waist welts follow the finished fabric. Underlying uniform pockets stay hidden by the jacket. The same garment builds in Character Builder and Props → Wearables.

- Opening Forge directly on authored clothing no longer reads the body pack before it is loaded. Garment type changes preserve the reference body, and handoff retains the previous prop recipe in Undo.

- **Hendrix lighting compatibility audit:** preserve tile-mask alpha with source-in blending, including detached render roots; support GPU-only `BaseTexture.dispose()` during resizing; honor positional texture frames and legacy frame-update notifications; keep original billboard quads hidden while their child slices draw. All five project plugins were scanned. The lighting plugin’s optional old batch renderer retains its guarded filter fallback.

- **Procedural plugin textures:** restored `PIXI.Texture.fromBuffer` and `BaseTexture.fromBuffer`, fixing the missing-method error reported by Hendrix 3D Light and Shadow while creating fog noise. Byte/float RGBA data, sampling, repeat, updates and disposal retain native GPU textures. Buffer resolution changes display size without cropping the stored pixels. Verified with real GPU pixels and the Sang Hendrix lighting project across world, village, indoor and return transfers.

- **Combat ragdolls:** defeated characters collapse with loose limbs and momentum from the killing blow, using the existing fall physics. Bodies settle above the ground, stop simulating at rest, and restore normal animation and weapon handling on revival. The Physics ragdoll setting controls this effect.
- **Target hit chance:** after choosing Attack or a skill in Tactical battles, a readable hit percentage appears above a valid hovered target, using the same forecast as the target panel.

- Grapple aim/tighten/pull poses reach toward the actual hook using the existing arm solver. The off-hand joins during tightening; one pose state carries directly into the ledge climb without dropping the arms. Carried weapons stow before the overlay runs, including fatal-fall ragdolls. `grapple-pose.test.cjs` covers arm positions, timing, repeated rendering, transformed stages, handoff and cleanup; `smoke/nw-grapple-motion.cjs` captures four live raid poses.
- Combat knockouts mark a distinct resting state, suspend ordinary animation/action playback, relax the rig and stow held weapons. The animation root cannot add a second fall to the combat transform. Ground support samples a bounded cloud from the posed skin; settled bodies reuse the correction, with no full vertex walk on a combat frame. Revival and saved fallen events restore the appropriate state; Action's actor presentation snapshot includes the flag. `downed-pose.test.cjs` and `smoke/nw-downed-motion.cjs` cover ground contact, weapon exclusion, resting and revival.

- Grapple previews enumerate the flood's actual reached bounds instead of assuming movement points equal tile distance. A two-point pull five cells away, subsequent walking and action-cost grapples at zero movement remain selectable. The flood tracks four bounds as nodes settle; previews reuse the completed result without another map search.
- Shadow passes prepare a depth material for a held mesh that joins after its character was registered. Such clones can retain the casting layer without `customDepthMaterial`; their normal lit shader then sampled the depth atlas being written. The native town audit traces that feedback to `rrShadowDynAtlas`; `shadow-maps.test.cjs` covers attachment, depth drawing, material restoration and reuse.
- Saved Auto CPU level 2 retains shadows using half the full caster budget, one moving light row per frame and a two-frame moving-row interval. High/Medium and explicit Low retain their settings; switching Auto budgets keeps the atlas and shader layout compatible. The editor has no automatic fallback, which explained the North Haven editor/game mismatch.
- Outside battle, a stamped building uses only its own cut-away bounds instead of expanding them across neighboring houses. Tactical building openings follow only the controlled active unit's actual position under a ceiling inside enclosing walls. Cursor/marks, enemies and unselected units no longer reveal houses. Actual threshold crossing invalidates openings during movement; leaving or deselecting closes them without the scenery hold. Movement picking skips only roofs actually cut by an opening, preserving visible roofs and grapple edges.
- Builder height help now says “Placement height: … above ground,” explains zero and Q/E, and uses larger, stronger text on an opaque panel. The existing Level card continues to control the same height offset.

- Common Events no longer inserts empty parameters for commands omitted from its private insert table: remaining simple commands use the shared dispatch table, Shop Processing opens its goods editor, and Reactor commands use their own dialogs on insertion and edit. Battle Processing and Start Battle on Map replace result structures while preserving branch bodies and confirming before nonempty branches are removed. Fadein/Fadeout carry their selected direction through the shared table. `common-event-command-coverage.test.cjs` and `events-in-play-sweep.test.cjs` cover dispatch, retired callbacks, continuation replacement, result bodies and fade direction.
- Detached Database and Event Editor popups use their owning document’s viewport for placement: Database row/action menus, event command menus (including Common Events and Troops), troop members, material and element pickers, and switch/variable placement. Animation Cell Properties and the effect-file browser move into the window that opened them; their HTML insertion previously bypassed the pop-out bridge. `smoke/nw-popout-audit.cjs` audits the live 25-page navigation and 136-command picker, normal and compact native windows, nested dialogs, save/cancel workflows and representative Database event commands. Rapid Database hide/reopen can still hang on RTX; tracked in OPEN-ITEMS.
- Cube captures bind safe reflection inputs at pass entry, including deferred faces between gameplay updates. Water with reflect=0 retains an active `rrEnvMap` sampler but has no reflective-material binding hook; the preceding main draw could leave that sampler pointing at the cube being written. The driver rejected those water draws with framebuffer feedback warnings when returning west through Forest Road toward North Haven. Capture failure also restores `autoClear`. `reflections.test.cjs` covers the actual zero-reflect water shader, deferred capture and failure cleanup; `smoke/nw-border-feedback.cjs --uncapped` reproduces the return route and can trace failing draw/sampler attachments.
- Model instances preserve the source skin sharing between body, hair and clothing meshes. Each character owns its cloned bones, inverse binds, skeletons and bone textures; distinct source skins remain distinct. This removes repeated palette construction, checks and uploads from Tactical world, reflection and shadow passes. Instance release disposes each shared skeleton once. `model-instance-skeletons.test.cjs` covers isolation and cleanup; `perf/nw-tactical-profile.cjs` compares the former separate palettes in the same live raid, checks frozen pixels, moves a unit and runs AI.
- Builder metal in the map renderer uses colored metallic F0, an integrated GGX environment response, normal/roughness detail, exported clearcoat and shadowed point/spot/beam/sun specular. The map's ambient supplies a hemisphere reflection where an LDR capture loses surrounding light. The former lacquer/glaze response made armor read as diffuse plastic. Rough metal retains its finish, and authored metal qualifies for a nearby reflection probe regardless of the old texture-keep value. Explicit model Surface overrides retain their existing behavior.
- Presentation draws every available refresh, including exact 120/180/240 Hz multiples, between fixed 60 Hz gameplay updates. Model roots, bones, articulated parts, camera and 2D character positions interpolate; game transforms are restored after the composite, including on failure. Interpolated model matrices are published between ticks without retraversing the entire static world.
- Removed automatic quality's half-rate draw suppression and ignore saved half-rate settings from older versions. Quality measures actual world draws against a 60 FPS stability floor (or the slower display), while presentation remains uncapped. F2 counts new world pictures (or composites outside a 3D map), rather than ticker callbacks that can reuse a picture.
