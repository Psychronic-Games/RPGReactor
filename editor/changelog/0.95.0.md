# RPG Reactor 0.95.0 - 2026-07-20

Cycle overview: [RPG Reactor 0.95.0: A More Complete Editor](../../docs/devlogs/2026-07-18-rpg-reactor-0.95.0.md).

0.94.9 was an internal development version and was never published; its changes ship in 0.95.0.

### Bundled content

- Psychronic and Looseleaf are bundled Character Generator styles, with Psychronic as the default. Project JavaScript and PNG styles remain supported and load automatically.
- Portal is available in the Animation Generator and as a baked Effekseer Energy recipe. The release registries contain exactly 76 Animation Generator recipes and 106 Effekseer recipes across nine categories, including 15 Energy recipes.

### Added

- Localization: `I18nDeepTranslations.js` supplies a generated 2,411-phrase catalog for every non-English locale and loads before `I18nManager`. Static source inventory detects `tText` calls plus consumed array/object schemas, while tests enforce identical locale key sets, placeholder preservation, translated Terms labels, and Arabic RTL direction. Broad editor routing now covers database and event-command editors, Forge tools, map/project controls, deployment UI, and the browser host while leaving project-authored data untouched.
- Control Variables Game Data: the operand row now opens a nested transactional selector modeled after RPG Maker. Item/Weapon/Armor/Actor choices use padded database IDs and names, Actor/Enemy/Character properties use stock parameter lists, Character choices include current-map events, and Party/Other/Last Action Data expose their canonical operands. The parent row displays a readable summary while preserving the exact stock `[type, param1, param2]` tuple. Last Action Data and Troop Lower/Upper Layer labels have explicit translations and no-English-fallback coverage in all 17 non-English locales.
- Release engineering: `release-editor.cjs` packages the tracked Reactor One Demo starter, rejects dirty publish sources, disables unverified bundled-runtime reuse, and validates pinned NW.js archives. Per-target manifests bind version, target, signing state, source commit, size, and SHA-256. GitHub publication accepts only a complete matching Linux/Windows/macOS/Web candidate set and uploads those exact bytes without rebuilding; Windows uses verified Authenticode metadata/signing, macOS uses hardened-runtime signing/notarization/stapling, and optional itch publication uses a pinned hash-verified Butler binary.
- Security and lifecycle: privileged HTML surfaces escape project-authored names, notes, messages, traits, JSON, and Forge values, and Character Generator folder opening uses argument-array execution. Project creation rejects traversal/reserved/non-empty destinations, same-project locks use exclusive no-follow token ownership, stale map loads cannot replace current state, and critical writes use exclusive random temporary files plus file/directory flushing.
- Database workspace: the modal now occupies nearly the full viewport with fixed shell chrome and independently scrolling navigation, list, and detail panes. Web layouts retain the same scroll ownership and reflow the specialized Types and Terms workspaces at narrow breakpoints.
- Cross-instance authored-data clipboard: `ReactorClipboard` carries versioned typed JSON over the NW.js/system clipboard with shared-file and localStorage fallbacks. Top-level database lists publish backward-compatible versioned `databaseEntry` payloads containing one or more ID-free records; Ctrl/Cmd- and Shift-selection, Ctrl/Cmd+A, batch Cut/Copy/Paste, and the context menu work across Actors, Classes, Skills, Items, Weapons, Armors, Enemies, Troops, States, Animations, Common Events, and Tilesets. Batch paste overwrites consecutive slots while retaining destination IDs, one Undo snapshot covers the batch, and lazy-list refresh restores selection, rendered depth, and scroll position. Whole maps retain their existing map/MapInfos/tileset transport. Individual trait/effect rows publish dedicated typed payloads; project-defined element, state, skill, Skill/Weapon/Armor/Equipment Type, and Common Event IDs resolve by a unique exact name in the target project, while missing or duplicate references reject the paste. Sentinel, enum, parameter, and flag IDs remain unchanged. Map, Common, and Troop event command lists support structural multi-selection and external-first typed payloads; block expansion protects branches/continuations, destination indentation is rebased, and clipboard publication completes before Cut deletes. Async operations abort if the project, category, focus, selection, destination data, row owner, event, page, troop, or route changes while clipboard access is pending. Incompatible categories/types are rejected; other referenced assets and numeric references are copied as authored.
- Types: five simultaneous dense panels preserve reserved ID 0 and every later numeric reference. Toggle/range selection, arrows, Enter/F2, Ctrl/Cmd+A/X/C/V, Delete/Backspace, toolbar actions, and a custom context menu support multi-row editing. Clipboard text preserves trailing blank rows, paste can safely grow the target array, async generation guards prevent stale clipboard completion, interior clear never renumbers IDs, and destructive maximum reduction requires confirmation.
- Terms: Basic Statuses and Parameters use paired compact grids, Commands uses a four-column grid, and all keyed Messages occupy a grouped Type/Text table with independent scrolling. Every text field has Cut/Copy/Paste/Select All context actions with delayed-clipboard guards.
- Conditional Branch: complete MZ code-111 support for condition types 0-13 and their subtypes, including variable RHS, Actor predicates, Enemy state/appeared checks, Character direction, equipment inclusion flags, Pressed/Triggered/Repeated buttons, Script, and all vehicles. No-change edits preserve original parameter arrays exactly; new configurations emit canonical arrays and command summaries cover every form.
- Advanced event commands: Control Variables adds a structured Advanced Expression operand covering arithmetic, power, min/max, `atan2`, random, bitwise operations, absolute value, square root, and degree-based sine/cosine. Loop uses direct stock Loop/Repeat Above insertion while preserving existing nested bodies; previously generated finite-loop structures remain byte-identical if encountered. Common Event keeps direct calls as stock code 117 and adds variable Common Event/current-map page calls. Conditional Branch adds extended keyboard pressed/triggered/repeated/released states, independent left/middle/right mouse states, wheel directions, and pointer X/Y comparisons. The same editors and indent-aware insertion behavior are available in Map, Common Event, and Troop command lists.
- Portable generated-command codec: `ReactorEventCommandCodec` emits strict canonical versioned tags only inside stock Script-bearing command layouts (111, 122, and 355). Generated JavaScript is syntax-checked before authoring, exact tag/body agreement is required when reopening, and malformed, edited, or unknown-version tags remain ordinary Script commands. Generated dynamic picture commands include direct stock MV/MZ fallback bodies rather than requiring Reactor to interpret custom parameter fields.
- Picture command extensions: Show/Move/Erase support variable picture IDs; Move supports variable duration; Erase supports One, Range, and All with direct or variable endpoints. Show and Move add initial/fixed/tweened angle, custom anchors, sine-wave offsets, and Overlay blend state. Negative scale uses `-2000..2000` and Quick Setting previews it directly instead of adding a separate flip control. The isolated `reactor_picture_extensions.js` module validates old-save defaults and runtime payloads; Overlay uses the advanced blend only when back-buffer support is active and otherwise degrades to Normal without warnings.
- Picture Quick Setting and movement preview: code 231's Quick Setting button now shares the Image row and opens a responsive surface using `System.advanced.screenWidth/screenHeight`, with MZ defaults for older projects. The screen grid occupies the center of a workspace extending one full screen beyond every edge; pointer capture continues updating X/Y beyond the visible workspace up to the command's ±9,999 range, so off-screen entrances are authorable instead of clamping at the screen edge. The fixed 1,000px dialog ceiling is gone: each layout pass measures wrapped controls and shell chrome, fits the exact project-aspect workspace against both available viewport dimensions, and recalculates on normal window and fullscreen resize. Origin, X/Y, independent width/height scale, and opacity are editable in the modal and remain transactional until Apply. Code 232 exposes the same controls plus live Duration frame entry and replayable easing animation: changing Duration affects the next Preview immediately, while Apply synchronizes it back to the main command. Event and common-event callers provide the current command list/index, the editor scans preceding Show/Move/Erase commands for that picture ID, preserves the latest image and endpoint, and animates from it using RPG Maker's four easing curves. No preceding visible Show produces an intentionally empty preview.
- Map-region sampling: `MapEditor` owns a dedicated six-plane stamp instead of forcing sampled map data through palette-layer/autotile placement rules. Right-drag captures a normalized, map-clipped rectangle from z0-z3, shadow z4, and region z5; the immutable stamp preserves exact autotile shapes and zero values. A side-effect-free canvas composite renders normal tiles, autotiles, higher tiles, shadows, and visible region tint into the hover preview, with an outlined footprint fallback for oversized selections. Pencil left-click/drag writes all planes directly, crops destination overflow, sends changed z0-z4 cells through one `updateTiles` batch, refreshes changed regions separately, and uses the existing begin/commit snapshot so a stroke creates one Undo entry while sampling creates none. Palette/region/tool/map/Event-mode changes clear the stamp. Event interaction teardown now unregisters only its named handlers instead of stripping map painting, sampling, and middle/Shift panning listeners from their shared PIXI container.
- Shift autotile placement: holding Shift while painting A1-A4 with Pencil, Rectangle, or Circle stores the selected shape directly without reconnecting painted tiles or reshaping their neighbors. Other layers and tools retain Shift-drag panning.
- A1 animation preference: `rr-settings.animateAutotiles` defaults on and is exposed as a checkbox in File → Options plus a compact synchronized `A1` checkbox beside the map zoom and coordinates. `TilemapManager.setA1AnimationEnabled` adds/removes the PIXI ticker without rebuilding the map; disabling resets both water sequences to frame zero and refreshes tracked A1 textures. The preference is global, survives sessions and project switches, and affects only the editor preview.
- Tests: added focused cross-instance clipboard, MV save, MV plugin visual, System 2 Magic Skills, event-branch structure, Event-mode double-click, database workspace, preview cleanup, localization source-audit, Unicode asset/index, project-open retry, package preflight, and PIXI pre-init game-loop coverage.
- Recursive assets: new shared `AssetFiles.js` performs deterministic recursive discovery without following symlinks, deduplicates extensionless names by declared format priority, normalizes stored separators to `/`, and resolves encoded desktop/Web preview URLs. It now backs BGM/BGS/ME/SE players and selectors, animation sheets/effects/timing SE, character/face/battler/tileset/battleback/parallax/title pickers, movement-route SE, and plugin `@type file` parameters. Core RPG Maker pickers expose only lowercase `.ogg`/`.png` files that the runtime can reconstruct; `$`/`!$` classification reads the final filename inside a nested path across every character preview surface.
- Picker navigation: new shared `PickerIndex.js` provides Audio-compatible Unicode grapheme sections, deterministic locale/numeric ordering, accent-insensitive Unicode case folding, and full-relative-path search. Its reusable browser adds a search field, clickable section rail, sticky headers, active-section tracking, and keyboard-selectable listbox options to `DatabaseEditorUI.showImagePicker`, `CharacterGraphicPicker`, and the Show Text face picker. Reopening an event character restores its exact file/index/pattern/direction, while a generation guard prevents slow stale image loads from replacing a newer selection.
- Picker search styling: search fields use a high-contrast theme-aware deep fill, accent border, and visible focus ring. A Reactor-styled accent clear button replaces Chromium's native blue search-cancel icon.
- Picker section navigation: clicking an earlier Unicode section after jumping downward now scrolls the picker list back up correctly. Navigation calculates the header's normal-flow position from preceding row heights and assigns the list's `scrollTop` directly, avoiding both `scrollIntoView` and Chromium's sticky-header offset reporting.
- System 1 start locations: Player, Boat, Ship, and Airship rows retain manual Map/X/Y inputs and add a visual Browse action backed by the Transfer Player map tree/canvas. Selection state is local until OK, each triplet commits together, nested expansion state survives tree rebuilds, search reaches nested maps, overlapping async renders cannot replace the latest preview, and the live `TilemapManager` is supplied through the database project proxy. The Title Screen picker now uses `RRPickerIndex.createBrowser` for searchable Unicode sections beside its image preview.
- Plugin search and actions: the load-order pane filters loaded plugins live by name, description, or author without losing their source indexes, while Add Plugin filters unused plugin filenames. Remove Plugin and Save Changes occupy a persistent shell-level footer in that order, so Save remains available with empty, single, or multiple selection. Source-derived `@help` documentation has separate literal case-insensitive highlighting, active/total match status, clear and wraparound previous/next controls, Enter/Shift+Enter and F3/Shift+F3 navigation, and a Plugin Manager-scoped Ctrl/Cmd+F shortcut. Highlight rendering uses text nodes rather than HTML, reloads clear stale help state, nested parameter/add dialogs suspend manager shortcuts, and controls expose accessible labels/live status without changing plugin manifests.
- Complex Plugin Parameters: struct parsing now terminates at each actual `*/`, so later schemas such as `YEP_OptionsCore`'s nested `Options` definition are available instead of producing “Could not find struct definition.” Schema-guided one-layer decoding preserves JSON-looking note/string leaves and simple-array strings; nested editors receive the source plugin's complete definition set, clone drafts for Cancel, support struct and scalar arrays, and synchronize Text edits before returning to Structure. Named rows replace JSON spew and add Edit/Delete/up/down controls, double-click editing, and full-row drag-and-drop ordering with theme-accent insertion feedback. Alternating list surfaces, stronger table framing, and neutral group headers derive entirely from active theme tokens; element editors use OK rather than an ambiguous Close action. New entries use schema defaults, notes use multiline editors, and stable grids align labels and fields. Saving recursively restores RPG Maker's array-of-JSON-strings format. A real nested `YEP_OptionsCore` fixture decodes and re-encodes byte-for-byte.

### Fixed

- Interactive editor deployment now uses developer-build runtime policy instead of immutable release policy. Latest Stable and user-selected NW.js versions may download with a clear unauthenticated-development warning, while release CLI builds still require pinned hashes. Cross-platform Windows packages skip ESM-only `resedit` metadata editing inside NW.js workers, fixing Linux-hosted Windows SDK builds; release candidates still apply and verify app-owned metadata under standalone Node before signing.
- Options localization: seven palette names and descriptions no longer inherit English in Traditional/Simplified Chinese, Russian, Portuguese, German, French, and Greek. All new A1 preference labels and toolbar help are translated in every supported locale, and high-visibility localization tests now reject English palette-description fallback across all 17 non-English languages.
- Troop preview Delete routing: clicking the battle canvas now gives it keyboard focus. Delete removes the selected troop member and stops propagation before the database list handler can clear the entire Troop record; with no member selected, preview-scoped Delete safely does nothing.
- Plugin detail scrolling: the right detail pane now owns vertical scrolling across metadata, expanded help, and Parameters. Help retains a nested scroller with a Notes-style lower-right vertical resize grip, Parameters keeps its natural height instead of shrinking into a near-zero flex child, and help-search navigation scrolls only the documentation viewport rather than every ancestor. Previous/Next/Clear controls use distinct theme button surfaces and visible disabled states; the outer search card uses a neutral border, reserving accent border/focus-ring feedback for the active text field.
- Actor equipment compatibility: shared `EquipSlots.js` treats an explicit class `<Equip Slot: ...>` list as authoritative for both `DatabaseActorEditor` and `BattleTestConfigModal`, without inspecting or special-casing plugins; classes without one use standard engine slots and actor/class item permissions. Slots with neither a compatible actor/class-permitted item nor a relevant stale value are omitted, while actionable stale values remain visible. `DatabaseTraitEditor` also preserves original IDs across blank entries in Weapon Types, Armor Types, and Equipment Types instead of assigning post-filter positions to equip/lock/seal traits.
- MV/YEP save compatibility: `runtime/libs/lz-string.js` implements stock MV's exposed API and byte-compatible Base64/UTF16 writers, loads before `reactor_mv_compat.js`, and is required by project/runtime packaging validation. Synchronous `StorageManager.load/save` and async `zipToJson` fallbacks decode legacy saves; local mode supports `localFileDirectoryPath`/`localFilePath`, browser mode supports `webStorageKey`, and custom save directories are created from the resolved path. A real large MV save fixture decompresses to valid JSON before YEP Save Core calls `JsonEx.parse`.
- Actor damage-popup compatibility: MOG BattleHud's actor-only `setupDamagePopup` captured Reactor's basic implementation before VE Damage Popup replaced the battler method, so enemies used Victor's complete HP/MP/TP/state/custom path while actors retained the stale limited path. Final plugin reconciliation now dynamically delegates side-view actors to the current `Sprite_Battler` implementation and keeps MOG's front-view face popup branch intact. The compatibility path is covered by `mv-plugin-visual-compat.test.cjs`.
- MV plugin visuals: `Window_DragonTreasure` moves its full-size contents sprite out of MZ's 168x8 client clip, restoring MOG Treasure Popup's 192x32 label without changing normal window clipping. PIXI 8 `TilingSprite.allowChildren` now supports legacy video-parallax parenting without warning state, and the VideoSource error bridge ignores only teardown events with no configured source while continuing to report actionable media errors.
- Database maximum safety without reduced capacity: `DataLimits.js` centralizes workload-based editor limits. Major databases and Common Events retain 9,999 slots; Animations and Tilesets retain 1,000. Elements rises to 512, Skill Types to 128, Weapon/Armor Types to 256, and Equipment Types to 128. The shared dialog displays each ceiling, while `DatabaseManager.changeMaximum` and `addEntry` enforce it defensively and permit existing oversized imports to be opened and reduced. Generic and Tileset lists remain continuous: the first 250 rows render immediately, and scrolling near the bottom appends the next batch in place. Growth serializes its template once, and 99,999 is rejected without allocation.
- Large-data overhead: the Database Cancel/Apply baseline is now retained as compact JSON rather than a second live clone of every database object. This particularly reduces the cost of Tilesets, whose shared `Tilesets.json` records each carry 8,192 flags even before a detail row is selected. Common Event trigger subsets are cached at map setup instead of filtering up to 9,999 records every idle frame.
- Extended levels and bounded iteration: Actor Initial/Max Level supports 1-999 and keeps Initial at or below Max. Standard level-99 Class parameter curves are linearly extrapolated through level 999 in both runtime and Battle Test without expanding every Class record; blank Class slots keep compact valid level-1 curves until authored, curve readouts use the correct indexes, the EXP preview uses the runtime formula through level 999, and three-digit levels fit the status window. Skill/Item Repeats and Attack Times+ support up to 100, with `Game_Action.numRepeats` applying the final runtime cap even to imported/plugin-modified data.
- Freedom for constant-time values: price, MP/TP cost, TP gain, action speed, success rate, and damage variance no longer inherit MZ-only editor clamps because those values do not multiply work. Effekseer scale/speed/rotation and sprite-cell pattern/scale/rotation/opacity remain bounded before live preview APIs receive them because those values reach rendering systems directly.
- Map scale and paste placement: new and pasted maps share a hole-reusing allocator, support 2,000 live maps with IDs through 9,999, and correctly produce `Map1000.json` and later variable-width filenames. The Transfer Player hierarchy now indexes children once instead of rescanning the entire map list for every tree node. Paste captures the currently selected/loaded map before asynchronous clipboard work, inserts the copy directly after it as a same-parent sibling, then normalizes and saves that sibling group; without a valid selection it falls back to the end of the root list.
- Database snapshots: `takeDatabaseSnapshot(true)` refreshes the active viewer's Cancel baseline after Save All, matching Apply and preventing a post-save Cancel from restoring older in-memory data.
- Tileset asset loading: the compact editor no longer depends on a non-null map renderer to retain the project path, and reused project context stays dynamic. All A-E thumbnails, tab previews, canvases, and full previews use the browser asset bridge or `pathToFileURL`, so Unicode, spaces, `#`, and other URL-significant path characters load correctly.
- Audio filename index: section keys now use normalized Unicode graphemes and locale-aware sorting instead of ASCII-only `A-Z`. Initials such as `É`, `Ü`, `Ω`, `Ж`, `不`, `あ`, and `한` appear directly in the left rail; numbers and punctuation continue to use `#`.
- Project opening: a live `.rpgreactor.lock` rejection no longer falls through to the generic invalid-project alert. - Event workflow: Event Editor sessions work on isolated drafts. Occupied tiles retain double-click editing, while bounds/occupancy checks and real-drag timing prevent accidental creation.
