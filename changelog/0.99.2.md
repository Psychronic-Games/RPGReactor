# RPG Reactor 0.99.2 (in development)

Work since 0.99.1. The full technical list is in the [editor changelog](../editor/changelog/0.99.2.md).

### Added

- **HDR effects.** An Effekseer effect can opt in to HDR rendering with a small `.hdr.json` file beside it: its light adds up in a floating-point buffer, gains bloom and is graded once for display. A normally graded copy of the effect plays instead when the computer cannot render it. Effects without the file draw exactly as before. See the [HDR effect overlay guide](../docs/HDR-EFFECT-OVERLAY.md).
